# Banking Loan Analysis

## Project Overview

This project analyzes banking loan application data to understand loan approval patterns and identify factors associated with loan approval outcomes.

The analysis was performed using Python and Tableau.

## Tools & Technologies

- Python
- Tableau
- Pandas
- Jupyter Notebook
- Data Visualization
- Exploratory Data Analysis (EDA)

## Skills Demonstrated

- Data Cleaning
- Data Analysis
- Exploratory Data Analysis (EDA)
- Data Visualization
- Loan Approval Analysis
- Dashboard Development
- Business Insights
- Data-Driven Decision Making

## Data Analysis

The analysis focused on:

- Loan application and approval patterns
- Approval rates by employment type
- Credit score and approval rate
- Annual income and approval rate
- Overall approved vs rejected applications

## Tableau Dashboard

An interactive Tableau dashboard was created to visualize loan application and approval patterns.

The dashboard helps explore:

- Approved and rejected loan applications
- Approval rates across employment types
- Credit score patterns
- Annual income patterns
- Key loan approval metrics

## Key Insights

- Rejected loan applications exceed approved loan applications, indicating a higher proportion of applications being rejected.
- Salaried customers have the highest loan approval rate compared with other employment types.
- Higher credit scores are generally associated with higher loan approval rates.
- Higher average annual income is associated with a higher loan approval rate.

## Recommendations

- Review the factors contributing to the relatively high number of rejected applications.
- Consider employment type as one of the factors when evaluating loan applications.
- Use credit score as an important factor in loan assessment while considering other relevant borrower characteristics.
- Consider annual income alongside credit score and other financial factors when assessing loan applications.

## Project Outcome

This project provided practical experience in using Python for data analysis and Tableau for interactive data visualization. It helped identify patterns in loan approval outcomes and demonstrated how data can support lending-related decision-making.
